本 skill 只指导测试内容生成，不负责案例调研、视频观看、开发部署、平台上架、发布或账号操作。

$ARGUMENTS

## 1. 题材必须让用户立刻想到自己

- 优先一个具体关系、阶段、场景或单一 IP，不做“历史人物大全”“你是什么样的人”这类宽泛命题。
- 好题目能回答“这和我此刻有什么关系”。例如把泛恋爱人格缩成“暧昧期的第一反应”，再具体到回消息、被靠近、突然冷场和想退缩。
- 使用单一 IP 时限定作品和核心角色，围绕粉丝熟悉的情境，不借角色名重新讲一套泛职场人格。
- 不用“超准”“看穿你”“真实阴暗面”制造承诺，不把娱乐测试包装成心理或医学诊断。

## 2. 结果类型先可辨认，再可分享

- 每种类型代表一种能被人认出的习惯反应，不是抽象优点的随机组合。
- 类型之间没有高低好坏。避免把一种类型写成标准答案，把其他类型写成需要被纠正的问题。
- 名称要短、具体、有画面，例如“直球行动派”“慢热观察派”，少用“智者”“守护者”“自由灵魂”等泛化标签。
- 每种结果必须包含：
  1. 类型名和一句像人话的概括；
  2. 一个能对应题目答案的具体行为瞬间；
  3. 这个反应可爱或有利的一面；
  4. 它容易卡住的地方，但不羞辱用户；
  5. 一句可尝试的小练习，而不是空泛建议；
  6. 一句适合分享的自述。

## 3. 题目写真实瞬间，不写人格问卷腔

- MVP 优先 10–12 个有区分度的情境，不为显得专业而堆到三四十题。
- 每题只问一个瞬间，例如“对方突然六小时没回消息”，不要同时问多个行为。
- 选项写“我会怎么做”，保持同一行为层级、相近长度和自然口语，不混用情绪、价值观和道德宣言。
- 不设置明显体面、成熟或正确的选项。让用户选择最像自己的答案，而不是最愿意成为的答案。
- 不在选项里暴露计分维度，不让用户能轻易按类型名称猜出每个选项对应谁。
- 避免同义反复。若两题测到的反应没有区别，删掉一题。
- 不直接询问抑郁、焦虑、创伤等临床状态，不浪漫化控制、折磨、自毁或胁迫。

## 4. 文案要像朋友说话，不像 AI 写评语

- 多写“你很像那个会……的人”，少写“你是一个……的人”。
- 把专业词换成日常说法，例如把“还没约定排他”改成“还没在一起”，把“确认对方意图”改成“看看对方是不是认真”；疑问句直接写“你会怎么回答”，不要写“你更像怎么答”。
- 使用“更像”“可能”“这次答案里”，不要根据十几道娱乐题断言用户的一生。
- 删除通用奉承和空泛词，如“独特的光”“内心力量”“灵魂共鸣”“真正的自己”“值得被爱”。
- 结果至少有一处能与用户刚刚做过的具体选择对应，避免换一个人也同样成立。
- 尖锐不等于伤人，温柔不等于夸奖。可以说“脑子比证据跑得快”，不要说“你就是缺爱”。

## 5. 计分必须一致、可解释

- 每个选项记录主倾向和辅助倾向，各类型在整份测试中的覆盖要可检查。
- 使用各类型自己的理论上限做归一化，避免某类型只因出现次数多就天然占优。
- 结果类型和条形图必须使用同一归一化口径排名，不能原始分选类型、归一化分画图。
- 并列规则要明确且稳定。分数只表示本次答案的倾向，不称为概率、能力或心理测量结果。
- 每种类型都必须能通过真实选项路径得到，不能只写文案而无法触发。

## 6. 分享不能牺牲隐私和信任

- 分享文案包含类型、个人化的一句自述和访问链接，不写保证准确或保证收益的宣传。
- 昵称只用于结果卡时，应允许留空，并清楚说明是否仅存本机。
- 明示“原创趣味测试，非心理诊断”；不要用专业术语增加虚假的权威感。
- 结果卡先保证本人愿意展示，再考虑朋友是否能看懂，不堆完整分析报告。

## 7. 交付前逐项自审

- 大声读一遍首页、所有选项和六种结果，删除不像人说话的句子。
- 检查每个结果是否有具体行为、优势、卡点和小练习，且没有高低贵贱。
- 检查所有选项长度、语气和行为层级是否相近，是否暴露了“正确答案”。
- 检查计分覆盖、并列规则、所有结果可达性，以及结果类型与图表第一名是否一致。
- 根据用户反馈和实际失败持续修订本 skill，只沉淀被新证据支持的原则，不把一次性审美偏好写成定律。
